# Dataset de conciliación sintético

Estos datos no tienen relación con bancos ni personas reales. **No se incluyen las transferencias internas de contraparte**: debes sembrar un dataset bancario consistente para verificar coincidencias, diferencias de monto, estados distintos, entrada duplicada y operación sin correspondencia. No es posible inferir una discrepancia de monto sin tener el registro interno contra el cual comparar.
